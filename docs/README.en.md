# Knowledge base on Rise of Legends rules

Russian: [README.md](README.md)

Everything gathered here is read straight from the installed game's own
archives: rule files, string tables, the `legends.exe` executable. No
guesswork — only what can be measured and checked again. This section
assumes the reader has nothing but the game itself.

Read in order; each document builds on the one before it.

1. [game-data.en.md](game-data.en.md) — where things live: which archives
   hold what, the four rule files, encodings and format pitfalls.
2. [rule-layers.en.md](rule-layers.en.md) — why an entry can exist in a rule
   file and still be invisible in battle: the three layers a record has to
   pass through.
3. [mechanics.en.md](mechanics.en.md) — what is actually driven by data, and
   what is hardcoded into the engine and unreachable by any edit.
4. [campaign-to-skirmish.en.md](campaign-to-skirmish.en.md) — carrying a
   campaign hero into a skirmish battle, and the seven pitfalls that come
   with it.
5. [mods.en.md](mods.en.md) — a look at four existing mods: what they
   changed and how that lines up with the sections above.
6. [model-formats.en.md](model-formats.en.md) — a separate branch about
   graphics: model and animation formats.

Last, as an appendix — the [reference tables](reference/README.en.md): lists of
units, buildings, technologies, crafts, campaign entities, and dictionaries
of tags and parameters. The reference tables don't explain how anything
works, only what things are called and where to find them; the meaning of
what's listed there is in the sections above.
